МОИ КАРТОЧКИ — инструкция для iPhone
===================================

Что умеет приложение
--------------------
• Создавать двусторонние карточки с любым собственным текстом.
• Переворачивать карточку касанием.
• Листать карточки свайпами вправо/влево или стрелками.
• Редактировать и удалять карточки.
• Хранить данные на устройстве и работать без интернета после первой загрузки.
• Скачивать резервную копию и восстанавливать карточки из JSON-файла.

ВАЖНО: архив ZIP — это исходные файлы приложения, а не файл .ipa.
Чтобы установить PWA на iPhone, его необходимо один раз разместить по HTTPS-адресу.

КАК ОПУБЛИКОВАТЬ БЕСПЛАТНО ЧЕРЕЗ GITHUB PAGES
----------------------------------------------
1. На Mac распакуй ZIP-архив. Внутри лежат index.html, app.js, style.css,
   manifest.webmanifest, sw.js и папка icons.
2. Открой https://github.com и войди в свою учётную запись (или создай её).
3. Нажми New repository. Назови репозиторий, например english-cards.
   Выбери Public, затем Create repository.
4. В репозитории выбери Add file → Upload files.
   Перетащи содержимое распакованной папки, а не сам ZIP:
   index.html, app.js, style.css, manifest.webmanifest, sw.js, папку icons.
   Важно: index.html должен находиться в корне репозитория.
   Нажми Commit changes.
5. Открой Settings → Pages.
   В разделе Build and deployment выбери Source: Deploy from a branch,
   Branch: main, Folder: /(root), затем Save.
6. После публикации на странице Pages появится адрес сайта вида:
   https://имя-пользователя.github.io/english-cards/
   Открой именно опубликованный адрес, не ссылку на файлы GitHub.

КАК УСТАНОВИТЬ НА IPHONE
-----------------------
1. Открой опубликованный адрес в Safari на iPhone.
2. Нажми кнопку «Поделиться» (квадрат со стрелкой).
3. Выбери «На экран Домой» / Add to Home Screen.
4. Если отображается переключатель «Открывать как веб-приложение», включи его.
5. Нажми «Добавить». На главном экране появится значок «Карточки».
6. Открой приложение, создай первую карточку и попробуй запустить его
   без интернета. После успешной первой загрузки файлы кешируются.

ХРАНЕНИЕ И РЕЗЕРВНАЯ КОПИЯ
--------------------------
Карточки хранятся локально в хранилище конкретной установки приложения,
а не в GitHub. Они не видны посетителям публичного репозитория.

Открой значок со стрелкой вниз вверху справа → «Скачать копию карточек».
Сохранится JSON-файл. Храни его в «Файлы», iCloud Drive или другом надёжном месте.
Для восстановления выбери «Восстановить из файла» и укажи этот JSON.
Внимание: восстановление ЗАМЕНЯЕТ текущие карточки.

Если удалить приложение или очистить данные Safari/сайта, карточки могут
потеряться. Периодически делай резервную копию. Данные в Safari и в
приложении на главном экране могут храниться раздельно.

ПРИМЕЧАНИЯ
----------
• Для первой установки и загрузки требуется интернет.
• Для публикации GitHub Pages нужен публичный репозиторий при бесплатном тарифе.
  Не загружай в репозиторий личные записи, резервные копии или пароли.
• В дальнейшем публикация новых версий требует обновления файлов репозитория.
• Не открывай index.html как файл с iPhone: для установки PWA нужен HTTPS.
• Приложение не отправляет карточки на сервер; данные сохраняются локально.
